Resolución del ejercicio N°11 de la unidad 2 de programacion 2.
Este programa simula un sistema automatizado de seguridad perimetral.
Permit la detección de movimiento mediante sensores distribuidos, los cuales generan avisos detallados y los envían de forma centralizada a una estación de monitoreo para registrar y rastrear incidentes activos en tiempo real.

Clases utilizadas:
Alerta
CentralMonitoreo
SensorPerimetral
